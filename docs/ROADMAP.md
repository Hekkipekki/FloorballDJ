# FloorballDJ – beslut och roadmap

## Plattformar (beslut 2026-09-26)

- Behåll en fullt fungerande Windows-version för PC.
- Utveckla även en funktionell macOS-version med samma funktionalitet som mål.
- iPad/iPadOS ingår inte. Ingen surfplatteversion planeras i detta spår.
- Mac-arbetet är ett separat framtida utvecklingsspår och ingår inte i Windows RC1.
- Återanvänd gemensam logik och profilformat där möjligt. Utvärdera Avalonia respektive XPF och ersätt Windows-specifika ljud-, fil-, licens- och uppdateringsdelar.
- Bevisa uppspelning, avbrytbar fade, separat förlyssning och profil/backup-kompatibilitet på fysisk Mac innan slutligt teknikval och tidsplan.

## Windows RC1

Version 0.40.0-rc.1 publiceras som release candidate (förhandsversion), inte som slutlig stabil utgåva. Se versionsanteckningarna i `releases/0.40.0-rc.1.md`.
