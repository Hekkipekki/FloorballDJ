# FloorballDJ 0.40.0 RC11

Startkontroll av uppdateringar och tydligare hjälp för Autoplay.

- Efter programstart kontrolleras den senaste publicerade versionen i bakgrunden. Bara när en nyare version finns visas en tyst ruta: Utdaterad version, med installerat och tillgängligt versionsnummer.
- Uppdatera hämtar installeraren genom det befintliga flödet med SHA-256-verifiering. Senare låter dig fortsätta och frågan kan visas igen nästa programstart. Ingenting laddas ned eller installeras automatiskt.
- Samma version, äldre versionsinformation, saknat internet, ogiltiga svar och tidsgräns ger ingen startruta eller felruta. Kontrollen blockerar inte starten och avbryts när programmet stängs. Hjälp → Sök efter uppdateringar finns kvar för manuell kontroll.
- Huvuduppspelning och förlyssning måste vara stoppade innan installationen startas. Osparade profiländringar hanteras före avslut.
- Den gröna sessionsmarkeringen döljs i Autoplays låtväljare. Bockarna för valda låtar finns kvar. Sessionshistoriken behålls och markeringen visas i den vanliga deckvyn.
- Hjälpen beskriver den ändrade köordningen, markeringsrutor, deck/sidor, fortsatt uppspelning, Klar/Escape, den tysta avslutsdialogen och uppdateringar vid start.

Riktade tester kontrollerar nya/samma/äldre versioner, Senare, offline, tidsgräns, stängning, versionsordning, svensk/engelsk dialog och sökbar hjälp. Startkontrollens regressionstester körs även i releaseflödet. Windows 10/11 x64, förhandsversion.

Installera RC11 en gång för att få automatiska besked om kommande versioner. RC10 och äldre får inte startkontrollen retroaktivt.

## English

FloorballDJ checks for updates in the background after startup. Only a newer version opens the quiet Outdated version dialog, showing installed and available versions. Update uses the existing checksum-verified installer flow; Later continues normally and allows another notification at the next startup. Nothing downloads or installs without your choice.

Current/older versions, offline errors, invalid data and timeouts are silent at startup. Closing cancels pending notification. Manual checks remain available through Help. Main and preview playback must be stopped before installation.

Autoplay's song picker hides the green session-played indicator while retaining playlist checkmarks and session history. Help now covers queue reordering, deck/page selection, continuous playback, Done/Escape, the quiet exit dialog and startup updates. Swedish/English UI and startup regression checks pass; startup checks also run in release CI. Windows 10/11 x64 prerelease.

Install RC11 once to receive automatic startup notifications for future versions.
