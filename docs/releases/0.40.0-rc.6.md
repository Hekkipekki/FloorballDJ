# FloorballDJ 0.40.0 RC6

Autoplay-listor kan nu kopplas till slumpprofiler, och dropdownmenyerna reagerar på hela klickytan.

## Autoplay per slumpprofil

- Under Verktyg → Inställningar → Autoplay finns det nya valet **Gäller för slumpprofil**. Välj exempelvis Dalen eller Dalendam för att aktivera listans snabbtangent endast i den slumpprofilen.
- Samma snabbtangent kan starta olika sparade spellistor i olika slumpprofiler. Överlappande Autoplay-kopplingar kontrolleras när inställningarna sparas.
- **Alla slumpprofiler** behåller det tidigare beteendet. Befintliga listor fungerar som tidigare.
- Kopplingen följer slumpprofilens identitet vid namnbyte, sparning och flyttbackup. En borttagen slumpprofil gör kopplingen inaktiv tills du väljer en ny.

## Dropdownmenyer

- Hela dropdownfältet är nu klickbart. Tidigare tog endast en smal remsa i mitten emot klick, vilket gjorde valet av aktiv slumpprofil svårt att öppna.
- Ändringen gäller programmets gemensamma dropdownstil. Redigerbara dropdownfält behåller sin textinmatning.

Kontroller passerar för Autoplay-kopplingar, inställningarnas Spara/Avbryt, återöppning, backup och synkmapp samt slumpinställningar och dropdownens klickyta med 553 och 2 000 ljudfiler.

RC6 är en förhandsversion för Windows 10/11, 64-bit.

## English

Autoplay presets can optionally be linked to a random profile under **Tools → Settings → Autoplay → Applies to random profile**. The shortcut is available only while that profile is active, and the same key can start different playlists in different random profiles. **All random profiles** preserves the previous behavior. Links survive renaming, saving and portable transfers; deleted random profiles leave their links inactive until reassigned.

Dropdown controls now respond across their entire visible surface instead of a narrow strip in the middle. Editable dropdowns retain text input. Checks cover scoped shortcuts, settings save/cancel/reopen, portable transfers, random settings and dropdown hit testing with 553 and 2,000 audio files.

Windows 10/11 x64 prerelease.
