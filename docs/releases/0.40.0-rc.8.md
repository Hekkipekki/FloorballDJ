# FloorballDJ 0.40.0 RC8

Två jingleknappar som använder samma ljudfil kan nu tona mellan varandra.

- Varje knapp har egen uppspelning och behåller sina start- och slutpunkter, även när grundfilen är densamma.
- Ett nytt klick på samma knapp tonar fortfarande ut den, om flera samtidiga klick inte är aktiverade.
- Mix, Duck, gränsen för samtidiga instanser och avslutad uppspelning hanteras per knapp.

Regressionstestet återskapade felet före rättningen och passerar efteråt på båda ljudutgångarna, med och utan återanvändning av ljudutgångar. Befintliga ljud- och volymtester passerar också.

RC8 är en förhandsversion för Windows 10/11, 64-bit.

## English

Different jingle buttons sharing the same source file can now crossfade while keeping their own clip start and end points. Pressing the same button again still fades it out unless multiple clicks are enabled. Mix, Duck, concurrent-instance limits and playback completion are handled per button.

The regression check reproduced the original failure and passes after the fix on both output routes, with and without output reuse. Existing audio and volume checks also pass. Windows 10/11 x64 prerelease.
