# FloorballDJ 0.40.0 RC2

Ny release candidate för Windows 10/11, 64-bit. Optimeringar och rättningar sedan RC1, med befintliga kärnfunktioner kvar.

## Nytt och förbättrat

- Snabbtangenter och stora slumpgrupper gör mindre arbete före uppspelning. Filernas tillgänglighet kontrolleras fortfarande när de används.
- Bakgrundsarbete och avgränsade cacheminnen för vågformer, ljudmetadata, profilskrivning och Autoplay minskar arbetet i gränssnittet.
- Slumpinställningar återanvänder deckvyer och synliga låtknappar. Valda låtar har läsbara titlar och mörk bakgrund.
- Autoplays deckfilter är en dropdown. Att lämna Autoplay med köade låtar kräver bekräftelse; musik som redan spelas stoppas inte. En direkt snabbtangent till ett annat deck visar det decket.
- Titelstorleken sparas per dator och följer inte med profiler eller flyttbackuper. Äldre profilers storlek används som startvärde första gången.
- Huvudutgångens limiter kan tillfälligt stängas av med en tydlig knapp. LUFS-normalisering och förlyssningens skydd behålls. Automatisk sänkning vid flera samtidiga ljud är av i nya profiler; befintliga uttryckliga val behålls.
- Nytt frivilligt val: håll huvudutgången aktiv med digital tystnad mellan låtar, för att motverka ljudenheters vila. Av som standard.
- Kort uttoning anpassas till återstående ljud så att den hinner nå tystnad innan klippet slutar. Aktiva Session/Talk-knappar får mörk bakgrund med grön markering.
- Flyttbackup behåller profilnamnet och tar med registrerade Autoplay-spellistor och deras ljud. Slumpgruppers snabbtangenter hör till respektive slumpprofil.
- Team Decks Stäng-knapp fungerar även i det fristående fönstret.

## Verifiering och återstående testning

Automatiska kontroller täcker bland annat sparning, metadata, Autoplay, slumpval, visuella tillstånd, backup, fade, ljudutgångar och lokala inställningar. Tidigare ProBook-mätningar har styrt prioriteringen; förbättringarna är avsedda för alla stödda datorer.

RC2 behöver fortsatt liveprovning i arena, långa sessioner och kontroll av faktisk ljudstart, vila/brus, enhetsbyten och olika skärmskalningar. Den tysta ljudströmmen är inte ännu bekräftad som lösning på det rapporterade arenabruset. Återanvändning av ljudutgångar finns som separat testprototyp och är inte på som standard.

Tempo/Rate är fortsatt inte fullt anslutna till huvuduppspelningen. RC2 är en förhandsversion inför 1.0.

## English

Windows 10/11 x64 release candidate with lower UI and playback preparation overhead, improved random-player views, an Autoplay deck dropdown, exit confirmation, and direct-shortcut deck navigation. Title size is now saved per computer, with one-time migration from older profiles. Transfer backups retain the profile name and registered playlists; random-group shortcuts belong to each random setup.

Includes a temporary primary-limiter bypass, optional silent primary-output keep-alive (off by default), short-tail fade handling, dark active controls, and the Team Deck close-button fix. Normalization and preview protection are retained; new profiles no longer enable automatic multi-sound headroom reduction by default.

Automated regressions cover these changes. Venue listening, long sessions, device changes and display scaling still need qualification. Audio-output reuse remains an opt-in diagnostic prototype. Tempo/Rate are not yet fully connected to main playback. This is a prerelease, not 1.0.
