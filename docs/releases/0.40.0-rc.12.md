# FloorballDJ 0.40.0 RC12

Beständiga lokala profilbackuper och en tydligare revisionshistorik.

- Originalprofilen ändras bara vid manuell sparning. Varje profil får en separat lokal backupfil, exempelvis Dalen backup.floorballdj.json, och en egen revisionshistorik.
- Spara och Spara inte behåller backuphistoriken. Även den sista ändringen före autosparningens fördröjning skyddas när Spara inte väljs.
- Sparade originalversioner, manuella sparningar, slutlägen efter Spara inte och versioner före återställning behålls. De 100 senaste tätare autosparningarna sparas separat.
- Hjälp → Backup och revisionshistorik visar datum, typ och ändringsbeskrivning. Välj en rad för att läsa ändringsloggen. Filtrera på sparade originalversioner eller sök efter låtnamn, deck, ändring och datum.
- Återställ för granskning skyddar nuvarande arbete och öppnar den valda versionen utan att skriva över originalet. Spara manuellt först när resultatet är rätt. Autoplay-kön följer nu också med korrekt vid återställning.
- Äldre lokal historik importeras. Profiler med samma namn i olika mappar blandas inte. Spara som till en ny fil förgrenar historiken.
- Hjälpen, statusraden och rutan för osparade ändringar förklarar skillnaden mellan originalprofil, lokal backup och revisionshistorik.

Profilbackuper innehåller profilens data och sökvägar till externa filer. Själva ljudfilerna kopieras med Skapa komplett flyttbackup.

Den samlade regressionssviten och riktade tester för sparning, Spara inte, omstart, återställning, backupfel, tidigare historik, rotation och svensk/engelsk historikvy passerar. Historiktesterna körs även i releaseflödet. Windows 10/11 x64, förhandsversion.

## English

Persistent local profile backups and revision history are now separate from the manually saved original. Save and Don't save retain local history, including the final edit before the autosave delay. Original versions, manual saves, Don't save checkpoints and pre-restore states are retained; the latest 100 frequent autosaves rotate separately.

Help → Backups and revision history shows dated versions, types, summaries and searchable change logs. Filter saved versions and restore for review before manually overwriting the original. Current work is protected first, and the Autoplay queue is restored correctly. Existing history is imported, same-named files remain separate and Save As forks history.

Help, status and unsaved-change text explain the behavior. Profile backups contain profile data and references to external files; use the complete transfer backup to copy audio files. Full regression and targeted history tests pass, with history checks included in release CI. Windows 10/11 x64 prerelease.
