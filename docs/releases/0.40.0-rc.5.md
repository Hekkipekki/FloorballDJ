# FloorballDJ 0.40.0 RC5

Smidigare sökning och manuell låtväxling i Autoplay.

- Mellanslag fungerar nu som vanlig text i Autoplays sökfält och andra textfält utan att aktivera tona ut/återuppta.
- Ny knapp **Spela nästa** följer köordningen eller väljer slumpmässigt när slumpning är aktiverad. Den använder inställd övergångstid och respekterar loop.
- Autoplays knapprad radbryts på mindre skärmar.

Kontroller för Autoplay och gränssnittet passerar, inklusive textinmatning, nästa låt, slumpning, loop och tom kö.

RC5 är en förhandsversion för Windows 10/11, 64-bit.

## English

- Space now remains available for typing in Autoplay search and other text fields instead of triggering fade/resume.
- The new **Play next** button follows queue order or shuffle, using the configured transition time and loop setting.
- Autoplay controls wrap on smaller screens.

Autoplay and interface checks pass, including text entry, next-song selection, shuffle, loop and empty queues. Windows 10/11 x64 prerelease.
