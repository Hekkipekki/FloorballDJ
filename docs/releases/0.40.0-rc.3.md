# FloorballDJ 0.40.0 RC3

Ny session vid varje programstart.

- Alla låtar räknas som ospelade när FloorballDJ startas om, på samtliga deck och decksidor. Session aktiveras automatiskt.
- Spelräknare sparas inte längre i profiler eller autosparningar. Tidigare sparad sessionshistorik i äldre profiler ignoreras också när profilen öppnas.
- Ospelade låtar prioriteras inom den pågående sessionen. Att spara eller byta deck behåller sessionens markeringar.
- Musik, decklayout och övriga profilinställningar behålls.

Verifierat med automatiska kontroller för ny installation, autosparning, standardprofil, saknad eller skadad standardprofil, avstängd sessionsräkning och upprepade omstarter. Sessionskontrollen körs även före varje releasebygge.

RC3 är en förhandsversion för Windows 10/11, 64-bit.

## English

Every application launch starts a fresh session with all songs unplayed across every deck and page. Session tracking is enabled automatically. Play counts are no longer saved in profiles or autosaves, and legacy saved counts are ignored when loading profiles. Saving and changing decks preserve the current session's played markers. Music, layouts and other profile settings are retained.

Automated regression checks cover new installations, autosave and default profiles, missing or corrupt default profiles, disabled tracking and repeated restarts. These checks also run before each release build. RC3 is a Windows 10/11 x64 prerelease.
