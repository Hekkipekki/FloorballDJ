# RC1 live-use corrections — 9 October 2026

Version remains 0.40.0-rc.1. Diagnostic revision: `rc-workflow-fixes-v1`. These corrections retain the previous optimization pipelines.

- Checked Session/Talk/Preview pills retain a dark surface with green text/indicator and an accent border. A local control template prevents the native Windows theme from painting the selected surface white. The limiter override retains its separate amber state.
- Manual deck-tab, deck-page, wheel and inline-search exits from Autoplay warn when the queue contains songs. No cancels the switch; Yes exits automatic queue progression and retains the queue for later use. This does not stop the song already playing.
- Direct and random/category deck shortcuts on the primary output leave Autoplay and show the played song's deck/page, including direct shortcuts whose ordinary deck-switch flag is off. Intentional live shortcut playback does not wait for an exit dialog. Preview playback retains the current primary view.
- Fade-out and fade-to-pause durations are bounded by the unread file/clip tail. The existing sample-based smoothstep curve and output-buffer drain remain. A long fade requested near the source end reaches silence before the source runs out instead of ending at a nonzero point in the curve. Zero-duration behavior remains intentional. Full listening checks in a venue are still needed.
- Portable backup uses the profile name shown in the app, even when the internal model still has its original new-project name. It changes the detached backup copy, preserving the currently open profile.
- Backup includes registered Autoplay playlist files, their flags/order/duplicates and media used only by those playlists. Shared deck audio is reused. Playlist references become relative to the backup profile; portable playlist version 3 resolves media relative to the playlist file after relocation. Old array and version-2 playlist input remains supported. Missing linked files are reported. Portable version-3 playlists require this updated reader.
- Saving or loading a playlist records its path in the current music profile so it can follow the next backup. Previously saved playlists that were never registered under Autoplay and have no stored path must be saved/loaded once in this build; the app cannot identify an unreferenced external file from old profile data.
- Random group keys belong to the selected random setup within the music profile. The same key can appear in different setups, and only the active setup routes those random groups. Assignment replaces a duplicate only within that setup, and retains jingle, Team Deck and Autoplay keys outside it; the existing random-before-direct shortcut precedence applies while the setup is active. Duplicating a setup gives its groups new identities. Save/reopen/backup retain each setup's keys.
- Team Deck's modeless Stäng button explicitly closes the window and releases its transition timer through the same Closed lifecycle as the title-bar X. Previously IsCancel alone only closed modal dialogs.
