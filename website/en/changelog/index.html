0.40.0 RC29 October 2026

Faster workflows and settings per computer

  • Less work before hotkey playback and fewer file checks in large random groups. Profile saving, metadata and waveforms are prepared in the background.
  • Random settings reuse song cards and deck views, with readable dark-theme titles. Autoplay has a deck dropdown and confirmation when leaving a queue.
  • Title size is saved on each computer and retained across profile changes and transfer backups.
  • Temporary primary-limiter bypass and optional silent audio between songs. Normalization and preview protection are retained.
  • Backups retain the profile name and registered playlists; random-group shortcuts belong to each random setup. Short-tail fades and the Team Deck Close button are fixed.
  • RC2 is a prerelease. Venue testing, long sessions and audio-device changes still need qualification before 1.0.
0.40.0 RC127 September 2026

First release candidate – clearer playback and customizable tabs

  • Duration and shortcut badges overlay jingle-button corners without reserving title space.
  • Song title, waveform and L/R meters stay visible during fade-out. The fade reaches silence before playback stops.
  • Press Space again during a Space-triggered fade to resume the same song from its current position and gain.
  • Tabs wrap across multiple rows. Set shared dimensions in Settings, or right-click → Customize tab… for individual width, height and a new row.
  • Complete transfer-backup progress wraps and scrolls on smaller screens.
  • Includes automatic session reset from beta 33. RC1 is a Windows prerelease ahead of a stable release; Tempo/Rate are still not fully connected to main playback.
beta.3326 September 2026

A fresh session on every app restart

  • Starting the app clears played-song history across all decks and pages and automatically enables Session.
  • Works with default profiles and restored autosaves, including older profiles with saved play counts.
  • Unplayed songs are still prioritized within the new session. Saving or switching decks does not reset it.
beta.3216 September 2026

More title space and clearer styling

  • Font and title size preview immediately in Settings and update existing jingle buttons when saved.
  • Jingle duration badges can be hidden. Centred titles have more space and can use more than two lines.
  • Dark dropdowns, help text and dialogs have been improved. Inter, Manrope and Atkinson Hyperlegible Next are included.
  • Random groups can limit consecutive songs from the same deck.
beta.3129 August 2026

Clear progress for complete transfer backups

  • Creating and restoring a complete transfer backup now displays a dedicated progress window instead of working silently in the background.
  • The window shows the current phase, percentage, file name and copied-file count so users can always see that work is continuing.
  • Background controls are locked during the operation and the dialog closes automatically when the backup is complete.
  • The progress flow works in both English and Swedish and is available from the Profile menu as well as the audio-file tool.
beta.3029 August 2026

Smoother follow-up songs and independent preview

  • The follow-up picker now has deck tabs, search and sorting for a clearer overview of large music libraries.
  • Each random group can set separate fade-out and fade-in times for a true overlapping crossfade without a silent gap.
  • The random-profile header is simplified to one clear selector with a separate rename action.
  • Preview on output 2 has its own volume and clickable timeline and affects neither output 1 nor session play history.
beta.2929 August 2026

Automatic follow-up songs and a clearer Help Center

  • Each random group can select one or more automatic follow-up songs that start after a natural song ending, but never after manual fade or stop.
  • Random-pool songs can be sorted by deck order, A–Z or Z–A, while the new follow-up picker searches every deck.
  • Autoplay playlists now store and restore both Shuffle and Loop, including when started by a shortcut.
  • The Help Center is divided into Basic, Advanced and Support, with full-text search and a dedicated Random Groups guide.
  • Small dialogs are more DPI-safe to avoid cropped controls.
beta.2829 August 2026

English interface and clear user folders

  • The saved language is applied consistently to the main window, menus and dialogs after restart.
  • The application creates and suggests separate Profiles and Created Jingles folders.
  • Generated mixes receive more reliable waveforms, while the sequence view in the jingle builder is cleaner.
beta.2729 August 2026

Separate random setups and a better mix workflow

  • Several teams can share one music profile while switching between completely separate random groups and shortcuts.
  • Selected random sounds are clearly marked and pool contents can be sorted for a better overview.
  • Autosave history more clearly shows which action created each revision.

beta.2629 August 2026

Per-page deck layouts and smarter loudness selection

  • Every deck page can be selected directly from the context menu and given its own rows and columns without changing the other pages.
  • Loudness and safety level can now select only audio that lacks a current analysis or does not yet have Auto gain enabled.
  • Status and summary information clearly distinguish unanalysed, analysed and balanced audio.
  • The compact deck-layout dialog opens at a normal size on the application's current monitor.
beta.2529 August 2026

Safer FLAC playback, file search and better dialogs

  • FLAC start positions are now applied on the same audio thread that performs playback, removing the COM error and making saved trim points reliable.
  • The jingle builder can search audio across every deck by title, deck, file name or path.
  • Dialogs adapt to the application's current monitor and remain inside its usable work area to reduce cropped controls on smaller computers.
beta.2426 August 2026

Language selection now applies throughout the interface

  • The Profile, Tools and Help menus now follow the saved application language after restart.
  • Submenus and context menus use the selected translation as well.
  • The first-launch language picker has a calmer, consistent layout without overlapping controls.
  • English remains the default for new installations and Swedish can be selected immediately.
beta.2326 August 2026

Swedish and English from the first launch

  • The installer now offers both Swedish and English.
  • The first application launch displays a clear language choice with English selected by default.
  • The language can be changed later in Settings without affecting profiles or backup files.
  • The website opens in English by default and provides clear flag-based language switches.
beta.2226 August 2026

Flexible decks and a new community

  • Decks can be sorted A–Z or Z–A directly from the deck-tab menu.
  • Colours can be applied to the complete deck, the current page or a custom selection of jingles.
  • Every deck page can use its own rows and columns, and the last active page is stored in the profile.
  • Search accepts spaces without triggering playback commands, while paste warns about identical jingles.
  • The website now links Instagram and includes a prepared anonymous community with secure moderation.
beta.2125 August 2026

Longer trial and clearer licensing

  • New computers now receive a fourteen-day automatic trial.
  • If the trial expires while the app is open, a clear warning and server-anchored 24-hour countdown are shown before the app closes safely.
  • License administration can edit customer details and generate secure replacement keys for verified customers who have lost a standard key.
beta.2025 August 2026

Long mixes, deck pages and smarter sessions

  • The jingle builder can analyse BPM, Camelot key and energy, then suggest smoother transitions and longer warm-up mixes.
  • Decks can be divided into compact pages. Scrolling over a tab changes page, while smaller layouts move overflow jingles to new pages automatically.
  • Session starts automatically, and random groups plus Autoplay Shuffle prioritise jingles that have not yet been played.
  • Search, hotkeys, help text, backup and layout migration have been updated for the new features.
beta.1923 August 2026

Team Deck and modern match automation

  • Team Deck connects a team's default goal jingle to searchable player transitions with selectable start positions and controlled fades.
  • Autoplay can use multiple profile-bound playlists with their own hotkeys and level adjustments.
  • The random song player has a dedicated modern workspace with global search results that open the correct deck automatically.
  • Profile backup, hotkeys, help text and audio management have been expanded for the new features.
beta.1822 August 2026

Transfer backup, stable audio and faster workflows

  • Complete transfer backup collects the profile, deck-organised original files, custom fonts and colour choices for easy restoration on another computer.
  • Stop and multiple simultaneous clicks use safer audio handling to reduce level drops, clicks and remnants from previous playback.
  • New search, queue and navigation tools make the audio library, Autoplay and hotkeys easier to manage.
  • Recent profiles, global clock, improved laptop layout and combined import of FloorballDJ profiles and Snap XML were added.
beta.1719 August 2026

More stable audio and flexible random groups

  • Empty decks are filtered out of random-group selections.
